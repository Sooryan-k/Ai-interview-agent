dryrun AI

An AI interview preparation platform that takes someone from a standing start
to interview-ready on any stack. Name a technology and it generates a complete
curriculum — levels, modules and topics — then teaches each one with study
notes, cheat sheets and checkpoint quizzes before putting you in front of a
realistic interviewer. Rounds run by voice: the interviewer speaks, listens to
the spoken answer, asks genuine follow-ups based on what was actually said, and
privately scores every answer as it goes.

Two rounds set it apart. It can read a public GitHub repository you wrote — file
tree, README and key source files — and interview you on your own design
decisions, which is where real interviews usually go and where people freeze.
And a depth ladder takes one topic and drills a rung deeper every turn until you
stall, then names the exact concept that stopped you. Alongside those are
whiteboard rounds graded by vision from the diagram you actually drew, coding
rounds that run your solution against real test cases, a salary negotiation
simulator against a recruiter with a hidden budget, and panel interviews where
three interviewers rotate, each with their own avatar and speaking voice. Every
round ends in a report card with model answers, a skill radar and a weakness
heatmap, plus delivery coaching — filler words, hedging language, pace and
speech clarity — computed entirely in the browser at no AI cost. Spaced
repetition, daily drills and streaks carry the habit between sessions, and the
whole thing runs on free infrastructure with no paywall.

Technologies: Next.js, React, TypeScript, Tailwind CSS, Google Gemini, Supabase (PostgreSQL, Auth, RLS), Web Speech API, Monaco Editor, Excalidraw, Recharts, GitHub API, Piston, Vercel
